КАК ЗАГРУЗИТЬ САЙТ С IPHONE

1. Распакуй этот ZIP.
2. На GitHub создай новый Public repository.
3. Назови его, например: kisa-love
4. Загрузи внутрь репозитория ВСЕ ТРИ файла:
   index.html
   photo1.jpg
   love-chat.jpg
5. Открой Settings → Pages.
6. В разделе Build and deployment выбери:
   Source: Deploy from a branch
   Branch: main
   Folder: / (root)
7. Нажми Save.
8. Подожди 1–3 минуты.
9. GitHub покажет ссылку на твой сайт.

Важно: названия файлов менять не нужно.
